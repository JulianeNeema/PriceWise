#  PriceWise 

PriceWise  is a responsive website that helps users compare
product prices from nearby small shops.

##  Goal

Help local shoppers find and compare prices before buying a product.

##  Current Version

This hackathon version is a frontend website built with:

- HTML
- CSS
- JavaScript

##  Future Version

The project can later become a full web application with:

- Flask
- Database
- Real shop registration
- Shop owner accounts
- Product management
- Price updates
- Location-based search
